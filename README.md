# QuickTranslate

> Мне похуй на эту программу: она сделана криво кривым вайбкодером и вообще задумывалась только для личного использования. Если кому-то ещё пригодится — буду рад. Пользуйтесь на здоровье.

Бесплатный portable-переводчик для Windows 10/11. Переводит английский и русский текст локально, без API-ключей и отправки текста в облако.

## Возможности

- Выделите текст и нажмите `Ctrl+C+C` — перевод появится в небольшом окне поверх текущего экрана.
- Перевод EN ↔ RU с автоматическим выбором направления.
- Распознавание текста на изображении или выделенной области экрана.
- Тёмная тема, значок в трее, история последних 50 переводов.
- Настраиваемые горячие клавиши и необязательный автозапуск вместе с Windows.
- Настройки и история хранятся в папке `Data` рядом с программой.

## Установка

Скачайте архив `QuickTranslate-Portable-0.3.1.zip` со страницы [Releases](../../releases), распакуйте **целиком** в папку, в которой у вас есть право записи, и запустите `QuickTranslate.exe`. Установка, регистрация и интернет для перевода не нужны. Архив крупный, потому что содержит модели EN/RU, OCR и необходимые среды выполнения.

Если обновляете версию 0.3, закройте приложение через значок в трее → «Выход», распакуйте архив обновления поверх старой папки с заменой файлов, затем снова запустите программу. Папку `Data` не удаляйте: в ней ваши настройки и история.

Если настройки или история не сохраняются, откройте «Настройки» → «Разрешить запись в Data» и подтвердите запрос Windows. Кнопка выдаёт право изменения **только текущему пользователю и только папке `Data`**. Другой вариант — перенести всю portable-папку туда, где у вас уже есть право записи.

## Исходники и сборка

Для сборки интерфейса нужен Windows x64 и .NET 9 SDK:

```powershell
dotnet restore .\QuickTranslate\QuickTranslate.csproj --configfile .\NuGet.Config
dotnet build .\QuickTranslate\QuickTranslate.csproj -c Release --no-restore
```

Этот проект собирает `QuickTranslate.App.exe`. Для работающего portable-пакета рядом с опубликованным приложением нужны локальный Python, библиотеки CTranslate2/SentencePiece, модели Argos EN/RU и данные Tesseract. Их нет в Git-репозитории; они включены в готовый архив выпуска. Корневой `Launcher.cs` — исходник небольшого загрузчика `QuickTranslate.exe` для структуры portable-пакета.

Перевод выполняется через [CTranslate2](https://github.com/OpenNMT/CTranslate2) и [SentencePiece](https://github.com/google/sentencepiece) на [моделях Argos](https://github.com/argosopentech/argospm-index). OCR использует [Tesseract](https://github.com/tesseract-ocr/tesseract). Сведения о компонентах, лицензиях и авторах данных находятся в `app/COMPONENTS.txt` и `app/licenses` внутри portable-архива.

## Ограничения

Поддерживаются только английский и русский языки. Максимум 20 000 символов на запрос и 40 МБ на изображение. Первый запуск модели может занять несколько секунд. OCR извлекает текст и переводит его; замены текста прямо на картинке пока нет.
